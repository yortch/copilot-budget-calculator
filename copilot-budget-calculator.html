Setup Checklist & Key Rules

  • Enable "AI credit paid usage" policy in enterprise settings — required for any metered usage
  • Set the Universal ULB to the recommended value above
  • Enable "Stop usage when budget limit is reached" on the enterprise budget — OFF by default; without it, charges accrue past the cap
  • Set individual ULB overrides for named power users (or use the excluded cost center pattern)
  • For Power Users who must never be blocked: own cost center + enable cost center exclusion — adds to bill ceiling but bypasses enterprise cap
  • Lowest remaining headroom wins — a high ULB does not protect a user if the enterprise budget is exhausted
  • Pool is shared across the whole enterprise — not per user, not per license type
  • ULB is always a hard stop; there is no "continue past limit" toggle for ULBs
  • Budgets are effective from the day they are set and cannot look back — usage before the set date is not governed; a mid-month start only covers the remaining days of that first month
  • Re-tune both ULB and enterprise budget at the promo→post-promo transition — the same ULB will produce more overage when pool shrinks
